# 智能车摄像头组（RT1064）

第二十一届智能车竞赛摄像头组的代码仓库。两份工程**互不影响**，按目录分开保存：

| 目录 | 内容 | 能不能改 |
| --- | --- | --- |
| [`初始例程/`](初始例程/) | 逐飞 RT1064 摄像头组初始例程，只实现低速直线行驶 | **不要改**，作为对照基线 |
| [`中期检查初版/`](中期检查初版/) | 在初始例程上迭代出来的正式工程，能连续跑完中期检查全程 | 在这里改，每次跑通提交一次 |

## 快速开始

1. 用 Keil MDK（5.33 以上）打开 `中期检查初版/demo/mdk/rt1064.uvprojx`
2. 按 `中期检查初版/demo/user/inc/main.h` 里的引脚定义核对实车接线
3. 编译下载，**先把车轮架空**确认电机方向和转向方向，再落地

## 当前状态（2026-10-19）

- 中期检查路线 A → B：全程约 12 m、8 个 90° 弯，实车 **30 s** 跑完，可以连续过
- 硬件基线：RT1064 主板 V3.1 + MT9V03X 摄像头 + 舵机（实测极限 112/70）+ 双电机编码器
- 赛道：0.5 m 宽白带铺在蓝地胶上，灰度上白带约 255、蓝地胶约 142
- 已知问题：无。实车已能全程跑完、前后轮都不出界（2026-10-19 验证）

各组负责的细节、调试方法和已知坑，见各自目录下的 `README.md`。
